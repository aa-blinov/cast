## Direction contract

THESIS: the conversation reads like a man page. Roles are section headings (bold caps, flush left), content hangs at a 4-column indent, and rank is carried by weight, case and one reversed plate, never by a coloured stripe or a gradient. Refuses the category default of coloured left rails, cyan-to-violet gradients and tracked-caps eyebrows over headings.

OWN-WORLD: the terminal's own foreground and background carry everything; nothing paints the page. One restrained accent (ochre) marks the selected row, a command or a path; muted grey for secondary text (held to 4.5:1); red only for failure. Bold and underline are the emphasis. Boxes are hairline, muted, with a bold title; no accent borders. Recognisable with all text removed: headings, an indent column, hairline rules.

STORY: a developer in a long session scans down the left edge for who spoke (YOU / TOOL / AGENT), reads code at a deeper indent, and sees state as a word or shape (failed, running) before colour. Cancelled or failed work says so in words.

FIRST VIEWPORT: a header line `CAST(1)` left, persona and model centred, version right; the transcript below as headed sections; a hairline rule above and below a plain composer; one status row. No wordmark gradient, no gradient rules.

FORM: man page, pick card, built from the dealt roll (key 09a73003); raises: from the timetable, rank by weight and case with one reversed plate per screen for what needs attention; from the emission-line rail, state by form and word, not hue.
